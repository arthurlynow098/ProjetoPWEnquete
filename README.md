# ProjetoPWEnquete

## Sobre o projeto

Aplicação de enquetes em ASP.NET Core, C# e .NET 9, com telas Razor, serviços, migrações e dependências de Identity, Entity Framework e SQL Server.

## Como explorar

Abra `ProjetoPWEnquete.sln` com SDK .NET 9. Configure uma conexão SQL Server de desenvolvimento e revise as migrações existentes antes de iniciar o projeto.
